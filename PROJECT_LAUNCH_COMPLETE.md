## 🎨 DESIGN DECISIONS

### Tech Stack Rationale:
- **Next.js 15** - Modern React framework, App Router, server actions
- **TypeScript** - Type safety, better developer experience
- **Tailwind CSS** - Rapid UI development, consistent design
- **Prisma** - Type-safe database ORM, easy migrations
- **OpenAI** - Best-in-class LLM for conversational AI

### Architecture:
- **Profile as JSON** - Structured, queryable, version-controlled
- **System Prompt Builder** - Dynamic prompt generation from profile
- **Command-driven UI** - Power user efficiency
- **Dark Theme** - Reduces eye strain, modern aesthetic
